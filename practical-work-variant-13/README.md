Задание 3 практики 9 относится к блоку «Списки»: два списка студентов объединяются в один отсортированный список сортировкой слиянием. Оно выполнено в папке «Практика 9». Аналогичное задание 3 практики 10 выполнено отдельно для массива студентов.

## Структура папок

- «Практика 8» — рекурсивные алгоритмы;
- «Практика 9» — вставки, быстрая сортировка, объединение списков студентов;
- «Практика 10» — Comparator, быстрая сортировка, сортировка слиянием, объединение списков;
- «Практика 11» — Date, Calendar, SimpleDateFormat, сравнение производительности коллекций;
- «Практика 13» — String, StringBuilder, StringTokenizer, разбор строк;
- «Практика 14» — регулярные выражения;
- «Практика 17» — картотека на односвязном, двусвязном и кольцевом списках.

## Запуск

Требуется JDK 8 или новее. В каждой папке практики находятся отдельные классы с методом `main`.

Командная строка (пример для практики 8):

```
cd "Практика 8"
javac -encoding UTF-8 *.java
java Task13 < input13.txt
```

Для практики 13 задание 6 читает имя файла, поэтому запускать нужно из папки практики:

```
cd "Практика 13"
javac -encoding UTF-8 *.java
java Task6
```

В качестве имени файла ввести `words.txt`.

Для практики 17 каждый вариант запускается своим тестером:

```
cd "Практика 17"
javac -encoding UTF-8 *.java
java SinglyTester < input_singly.txt
java DoublyTester < input_doubly.txt
java CircularTester < input_circular.txt
```

Либо можно запустить тестер без перенаправления ввода и работать с меню вручную.

Если в консоли Windows вместо русских букв выводятся посторонние символы, перед запуском нужно выполнить `chcp 65001`.

В IntelliJ IDEA достаточно открыть папку практики как проект, указать JDK и запустить нужный класс.
