## Задание 1. Фамилия разработчика и даты получения и сдачи задания

Условие: вывести фамилию разработчика, дату и время получения задания, а также дату и время сдачи. Для сдачи использовать класс `Date` из пакета `java.util`.

Решение. Дата получения задания задаётся через `Calendar`: 10 ноября 2026 года, 9:00. Время сдачи берётся из `new Date()`, то есть на момент запуска программы. Обе даты форматируются через `SimpleDateFormat` с шаблоном `dd.MM.yyyy HH:mm:ss`.

Файл: `Task1.java`.

Результат:

```
Разработчик: Лобасов Г.Г.
Задание получено: 10.11.2026 09:00:00
Задание сдано: 17.11.2026 03:38:02
```

Время сдачи зависит от момента запуска программы.

## Задание 2. Сравнение текущей даты с введённой

Условие: приложение сравнивает текущую дату с датой, введённой пользователем.

Решение. Дата вводится в формате `dd.MM.yyyy` и разбирается через `SimpleDateFormat`. Для проверки корректности включён строгий режим `setLenient(false)`: например, дата `31.02.2026` будет отклонена. Время у обеих дат обнуляется через `Calendar`, чтобы сравнивались именно календарные дни. Разница вычисляется в миллисекундах и переводится в дни. Если дата введена неверно, выводится сообщение об ошибке.

Файл: `Task2.java`.

Результат:

```
Введите дату в формате dd.MM.yyyy: 20.11.2026
Текущая дата: 17.11.2026
Введённая дата: 20.11.2026
Введённая дата позже текущей на 3 дн.
```

## Задание 3. Дата рождения в классе Student

Условие: добавить в класс `Student` поле для даты рождения, переписать `toString()` и разработать метод, возвращающий дату рождения в заданном формате.

Решение. В классе `Student` добавлено поле `Date birthDate`. Метод `getFormattedBirthDate(int style)` принимает стиль форматирования `DateFormat.SHORT`, `MEDIUM` или `FULL` и возвращает строку, полученную через `DateFormat.getDateInstance(style, new Locale("ru", "RU"))`. Локаль задана явно, чтобы названия месяцев и дней недели выводились по-русски. Метод `toString()` использует средний формат.

Файлы: `Student.java`, `Task3.java`.

Результат:

```

Короткий формат: 15.03.2005
Средний формат: 15 мар. 2005 г.

```

## Задание 4. Создание Date и Calendar по данным пользователя

Условие: сформировать объекты `Date` и `Calendar` по введённым году, месяцу, числу, часам и минутам.

Решение. Пользователь вводит пять чисел. Объект `Calendar` очищается методом `clear()`, чтобы не остались текущие секунды и миллисекунды, после чего поля устанавливаются методом `set`. Месяц в `Calendar` нумеруется с нуля, поэтому из введённого номера вычитается единица. Объект `Date` получается из календаря методом `getTime()`.

Файл: `Task4.java`.

Результат:

```
Введите год: 2026
Введите месяц (1-12): 11
Введите число: 17
Введите часы: 14
Введите минуты: 30
Объект Calendar: 17.11.2026 14:30
Объект Date: 17.11.2026 14:30
Миллисекунды с 01.01.1970: 1794915000000
```

## Задание 5. Сравнение ArrayList и LinkedList

Условие: сравнить время выполнения операций вставки, удаления, добавления и поиска для `ArrayList` и `LinkedList`.

Решение. Для каждой операции создаются новые списки по 20 000 элементов. Время измеряется через `System.nanoTime()` и переводится в миллисекунды. Проверяются добавление в конец и в начало, вставка в середину, поиск элемента, удаление из начала и из середины.

Файл: `Task5.java`.

Результат на тестовой машине:

```
Операция                          ArrayList, мс   LinkedList, мс
Добавление в конец                        1,749            1,631
Добавление в начало                      50,985            2,403
Вставка в середину                       26,637          539,863
Поиск элемента                          337,312          724,420
Удаление из начала                       21,487            2,283
Удаление из середины                     11,058          161,496
```

Вывод. `ArrayList` хранит элементы в массиве, поэтому быстро работает по индексу, но вставка и удаление в начало требуют сдвига всех элементов. `LinkedList` быстро добавляет и удаляет элементы в начале, так как достаточно изменить ссылки, но доступ к элементу по индексу требует прохода по списку. Поэтому вставка в середину для `LinkedList` оказалась значительно медленнее: каждый раз выполняется поиск нужной позиции. Добавление в конец у обоих списков примерно одинаково, поскольку в `ArrayList` массив расширяется амортизированно. Поиск по образцу медленнее у `LinkedList` из-за последовательного доступа к элементам.
