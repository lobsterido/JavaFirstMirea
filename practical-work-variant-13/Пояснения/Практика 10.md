## Задание 1. Класс Student

Класс `Student` содержит поля:

- имя;
- фамилия;
- специальность;
- курс;
- группа;
- средний балл.

Для всех полей созданы геттеры и сеттеры, конструктор принимает все переменные экземпляра. Метод `toString()` выводит поля в виде таблицы.

Файл: `Student.java`.

## Задание 2. Класс SortingStudentsByGPA

Класс `SortingStudentsByGPA` содержит массив студентов `iDNumber`, реализует `Comparator<Student>` и включает методы:

- `setArray()` — заполняет массив тестовыми данными;
- `quicksort()` — быстрая сортировка по среднему баллу по убыванию;
- `mergeSort()` — сортировка слиянием по тому же критерию;
- `outArray()` — вывод массива;
- `sortBySurname()` — дополнительная сортировка по другому полю, по фамилии.

Компаратор сравнивает баллы в обратном порядке: `Double.compare(second.getGpa(), first.getGpa())`. Поэтому первым идёт студент с максимальным баллом.

Быстрая сортировка использует последний элемент как опорный и рекурсивно сортирует части массива. Сортировка слиянием делит массив пополам, рекурсивно сортирует половины и объединяет их. При слиянии сравниваются баллы студентов, и в результат записывается больший из двух текущих элементов.

Сортировка по фамилии выполнена через `Arrays.sort` с компаратором `Comparator.comparing(Student::getSurname)`, то есть используется другое поле и другой способ задания критерия.

Файлы: `Student.java`, `SortingStudentsByGPA.java`.

## Задание 3. Объединение двух списков студентов

Условие: объединить два списка данных о студентах в один отсортированный список.

Решение. Оба исходных массива упорядочены по среднему баллу по убыванию. Метод `mergeLists` выполняет классическое слияние: два индекса перемещаются по массивам, и на каждом шаге в результат записывается студент с большим баллом. Когда один массив заканчивается, остаток второго копируется в результат. Итоговый массив сразу получается отсортированным, без повторной сортировки. Сложность — O(n + m).

Файлы: `Student.java`, `MergeStudents.java`.
