## Задание 1. Сортировка массива студентов вставками

Условие: создать тестовый класс, который формирует массив класса `Student` с полем `idNumber` и сортирует его методом вставок.

Решение. Класс `Student` содержит имя, фамилию, номер студенческого и средний балл, а также конструктор, геттеры, сеттеры и метод `toString()`. В классе `Task1` создаётся массив из шести студентов, который выводится до и после сортировки.

Алгоритм вставками реализован в методе `insertionSort`. Начиная со второго элемента, текущий студент сохраняется в переменной `current`, а все предыдущие элементы с большим номером сдвигаются вправо. После сдвига студент устанавливается на свободное место. Время работы — O(n²), дополнительная память — O(1).

Файлы: `Student.java`, `Task1.java`.

## Задание 2. Быстрая сортировка по среднему баллу

Условие: класс `SortingStudentsByGPA` должен реализовать интерфейс `Comparator` и сортировать студентов по итоговому баллу по убыванию алгоритмом быстрой сортировки.

Решение. Класс реализует `Comparator<Student>`. Метод `compare` возвращает `Double.compare(second.getGpa(), first.getGpa())`, поэтому студенты с большим баллом считаются меньшими и располагаются в начале массива.

Быстрая сортировка реализована рекурсивно. Опорным элементом выбран последний элемент участка. В методе `partition` массив переставляется так, чтобы слева от опорного элемента находились студенты с баллом не меньше опорного, а справа — с меньшим баллом. Затем рекурсивно сортируются обе части. Средняя сложность — O(n log n), худшая — O(n²).

Файлы: `Student.java`, `SortingStudentsByGPA.java`.

Результат:

```

2      Соколов      Иван       3,80
5      Попова       Ольга      4,40
3      Лобасов      Григорий   5,00

Студенты после быстрой сортировки по среднему баллу (по убыванию):

```

## Задание 3. Объединение двух списков студентов

Условие: объединить два списка данных о студентах в один отсортированный список с использованием алгоритма сортировки слиянием.

Решение. Списки представлены через интерфейс `List<Student>` и `ArrayList`. Сначала каждый список сортируется методом `mergeSort`. Массив делится на две половины, каждая сортируется рекурсивно, после чего две упорядоченные половины сливаются в исходный список. Сравнение выполняется по среднему баллу по убыванию, поэтому первым идёт студент с большим баллом. Затем метод `mergeLists` сливает два уже отсортированных списка в один, также сравнивая баллы. Повторная сортировка результата не нужна.

Сложность сортировки — O(n log n), объединения — O(n + m), дополнительная память — O(n). Используется устойчивое слияние: при равных баллах раньше остаётся студент из левой части.

Файлы: `Student.java`, `Task3.java`.
