Вариант 13, выполнены задания 13–17.

## Задание 13. Члены последовательности с нечётными номерами

Условие: последовательность натуральных чисел вводится по одному в строке и заканчивается нулём. Нужно вывести первое, третье, пятое и следующие числа с нечётными номерами. Глобальные переменные и параметры функции использовать нельзя, функция сама читает данные и выводит результат.

Решение. Функция `printOdd()` читает очередное число. Если это ноль, работа заканчивается. Иначе число выводится, после чего читается ещё одно число (оно стоит на чётной позиции и пропускается). Если пропущенное число не ноль, функция вызывает себя. Текущий номер позиции хранить не нужно: он определяется самой структурой рекурсии. Глубина рекурсии равна половине количества элементов.

Файл: `Task13.java`.

Результат для ввода `1 2 3 4 5 6 7 8 9 0`:

```
1
3
5
7
9
```

## Задание 14. Цифры числа слева направо

Условие: вывести цифры натурального числа в обычном порядке, без строк, массивов и циклов.

Решение. Базовый случай — число меньше 10: выводится единственная цифра. Иначе сначала рекурсивно обрабатывается число без последней цифры (`number / 10`), а затем выводится последняя цифра (`number % 10`). Благодаря такому порядку цифры печатаются слева направо.

Файл: `Task14.java`.

Результат для числа 57319:

```
Введите натуральное число: 57319
5 7 3 1 9
```

## Задание 15. Цифры числа справа налево

Условие: вывести цифры числа в обратном порядке без строк, массивов и циклов.

Решение. Сначала выводится последняя цифра `number % 10`, затем выполняется рекурсивный вызов для `number / 10`, пока число не станет меньше 10. В отличие от задания 14, вывод выполняется до рекурсивного вызова.

Файл: `Task15.java`.

Результат для числа 57319:

```
Введите натуральное число: 57319
9 1 3 7 5
```

## Задание 16. Количество элементов, равных максимуму

Условие: найти, сколько чисел последовательности равны её наибольшему элементу. Последовательность заканчивается нулём, глобальные переменные использовать нельзя, функция не получает параметров, кроме используемых для возврата значений.

Решение. Так как в Java нельзя вернуть два значения через параметры, создан вложенный класс `Result` с полями `maximum` и `count`. Функция `countMaximum()` читает число, рекурсивно получает результат для остатка последовательности и сравнивает текущее число с максимумом остатка:

- если остаток пуст или текущее число больше максимума, результат равен `(value, 1)`;
- если числа равны, счётчик увеличивается на единицу;
- иначе возвращается результат остатка.

Файл: `Task16.java`.

Результат для ввода `4 7 2 7 9 1 9 5 9 0`:

```
3
```

## Задание 17. Максимум последовательности

Условие: найти наибольшее число последовательности, которая заканчивается нулём. Параметры в рекурсивную функцию передавать нельзя, глобальные переменные использовать нельзя.

Решение. Функция `maximum()` читает число. Ноль является признаком конца и возвращает 0. Для остальных чисел рекурсивно находится максимум оставшейся части, после чего возвращается `Math.max(value, nextMaximum)`. Так как последовательность состоит из натуральных чисел, ноль не может оказаться её максимумом.

Файл: `Task17.java`.

Результат для ввода `12 45 7 45 3 0`:

```
45
```
