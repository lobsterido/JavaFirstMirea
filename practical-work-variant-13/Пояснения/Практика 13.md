## Задание 1. Методы класса String

Условие: выполнить последовательность действий над строкой `"I like Java!!!"`: вывести последний символ, проверить окончание `"!!!"`, начало `"I like"`, наличие `"Java"`, найти позицию `"Java"`, заменить `"a"` на `"o"`, преобразовать к верхнему и нижнему регистру, вырезать слово `"Java"`.

Решение. Для поиска последнего символа используется `charAt(length() - 1)`. Проверки выполняются методами `endsWith`, `startsWith`, `contains`, позиция находится методом `indexOf`. Замена символа выполняется методом `replace`, регистр меняется методами `toUpperCase` и `toLowerCase`. Слово `"Java"` вырезается двумя вызовами `substring`: берётся часть до найденной позиции и часть после слова.

Файл: `Task1.java`.

Результат:

```

Последний символ: !
Заканчивается на "!!!": true
Начинается на "I like": true
Содержит "Java": true
Позиция "Java": 7
Замена "a" на "o": I like Jovo!!!
Верхний регистр: I LIKE JAVA!!!
Нижний регистр: i like java!!!
Без слова "Java": I like !!!
```

## Задание 2. Класс Person и сокращённое ФИО

Условие: разработать класс `Person` с методом, возвращающим фамилию и инициалы. Имя и отчество могут отсутствовать. Программу оптимизировать по быстродействию.

Решение. Метод `getShortName()` собирает результат в одном объекте `StringBuilder`. Сначала добавляется фамилия. Если имя задано и не пустое, добавляется его первая буква и точка. Отчество обрабатывается только при наличии имени, при этом проверяется, что оно не равно `null` и не пустое. Конкатенация через `+` не используется, поэтому не создаётся большое количество промежуточных строк. Проверки пустых значений не дают возникнуть `NullPointerException` и лишним точкам.

Файлы: `Person.java`, `Task2.java`.

Результат:

```

Иванова А.
Петров

```

## Задание 3. Класс Address

Условие: из строки вида «Страна[d] Регион[d] Город[d] Улица[d] Дом[d] Корпус[d] Квартира» выделить части и записать их в поля класса. Пробелы в начале и конце частей нужно убрать. Предусмотреть два варианта разбора: через `split()` с запятой и через `StringTokenizer` с разделителями `,`, `.`, `;`.

Решение. Класс `Address` содержит семь строковых полей. Метод `parseWithSplit` разбивает строку по запятой. Метод `parseWithTokenizer` создаёт `StringTokenizer` с набором разделителей `",.;"` и собирает лексемы в список. Оба метода передают массив частей в общий метод `fill`, который вызывает `trim()` для каждой части. Если частей меньше семи, отсутствующие поля остаются пустыми.

## Задание 5. Преобразование телефонного номера

Условие: получить номер в формате `+<код страны><10 цифр>` или `8<10 цифр>` и привести его к виду `+<код страны> <три цифры>-<три цифры>-<четыре цифры>`.

Решение. Из строки удаляются все символы, кроме цифр, с помощью `replaceAll("[^0-9]", "")`. Последние десять цифр считаются номером, остальные — кодом страны. Если код равен `8`, он заменяется на `7` (российский формат). Затем номер разбивается на группы по три, три и четыре цифры. Если цифр меньше одиннадцати, выводится сообщение о некорректном номере.

Файл: `Task5.java`.

Результат:

```
+79175655655 -> +7 917-565-5655
89175655655 -> +7 917-565-5655
+104289652211 -> +10 428-965-2211
```

## Задание 6. Цепочка слов

Условие: прочитать из консоли имя файла со словами, разделёнными пробелами, и с помощью `StringBuilder` расположить слова так, чтобы последняя буква каждого слова совпадала с первой буквой следующего (без учёта регистра). Каждое слово используется один раз.

Решение. Файл читается через `Files.readAllBytes` с явной кодировкой UTF-8, после чего разбивается по пробельным символам. Для поиска порядка используется рекурсивный перебор с возвратом: первое слово фиксируется, затем перебираются ещё не использованные слова, у которых первая буква совпадает с последней буквой текущего. Если цепочка построена из всех слов, результат возвращается. Если очередной вариант не подходит, последнее слово удаляется из `StringBuilder` методом `setLength`, а слово снова помечается как неиспользованное. Такой перебор гарантирует, что каждое слово встречается ровно один раз, и находит решение даже тогда, когда жадный выбор приводит в тупик.

Файлы: `Task6.java`, `words.txt`.

Содержимое `words.txt`:

```
rat table tiger eagle elephant
```

Результат:

```
Введите имя файла: words.txt
rat table eagle elephant tiger
```
